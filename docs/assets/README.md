# Documentation artwork

- `hero.jpg`: README cover, 1600 × 900.
- `overview.jpg`: three views of the production popup using synthetic data, 1600 × 900.
- `install.svg`: illustrated installation guide; not a Chrome screenshot.
- `social-preview.jpg`: repository social preview, 1280 × 640.
- `icon.svg`: vector version of CiteLog's existing smiling-book icon.

Names, article titles, dates, and counts in the examples are illustrative. The screenshots use the actual extension HTML, CSS, and JavaScript with a local mock Chrome API; no Scholar request is made. The extension interface is currently Simplified Chinese.

These assets are covered by the project's MIT license. Google Scholar is named to describe compatibility; CiteLog is an independent project.
