# Introducing CiteLog

A useful first visit matters more than a large feature list: show the citation change, make the download easy to find, and help a new user get to a successful first check.

## Before sharing

- Finish a week of local use, including sleep/resume, notifications, and source-page comparisons. Keep what has not been verified explicit.
- Publish the release assets together with the public repository so the download button works.
- Try the installation instructions with one person who has not seen the project. Fix the step where they hesitate.
- Prepare a short real-use walkthrough: bind a profile, open a recorded change, then show how manually visited sources are stored. Label any example data.

## Places to share, when ready

Start with research colleagues and relevant academic-tool communities. Explain the problem you experienced, show one screenshot, and ask for feedback on installation and daily use. Follow each community's rules and identify yourself as the creator. Send announcements only after reviewing the final wording and destinations.

A focused first release, readable English documentation, thoughtful responses to early issues, and a short installation path can help people try and recommend the project. GitHub Trending placement is not predictable or guaranteed. Do not buy stars or ask people to create artificial activity.

## English announcement draft

I kept noticing my Google Scholar citation count go up, then trying to work out which paper had changed. So I built CiteLog: a small Chrome popup that records daily observed changes and per-paper updates.

Records stay in your browser. It checks the profile at a configurable interval and can send a desktop reminder. Citing articles are saved only when you open their Scholar source pages yourself; it does not automatically crawl those lists.

The first preview is MIT licensed and has a three-step manual install. The interface is currently Chinese, with English and Chinese documentation. I'd especially appreciate feedback on installation and whether the daily record is useful in practice.

[Project and installation guide](https://github.com/LilanOvO/citelog)

## 中文发布文案草稿

以前打开 Google Scholar，发现总引用涨了，还得逐篇找是哪篇论文有变化。我做了一个小插件 CiteLog，把总引用、每日观察到的变化和逐篇论文更新放到浏览器弹窗里。

记录保存在本机，可以自定义检查间隔、开启桌面提醒。引用来源仅在自己打开 Scholar 来源页时记录，不会自动爬取来源列表。

目前是 MIT 开源试用版，下载、解压、加载文件夹即可安装。欢迎试用，也想听听大家在安装和日常使用中遇到的问题。
