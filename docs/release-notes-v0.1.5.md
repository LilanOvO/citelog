CiteLog v0.1.5 · Early preview · Chrome 116+ · Chinese interface

## Changes

- Manual checks no longer have a fixed waiting interval. Repeated clicks during an active check share that check.
- Shorter English and Chinese READMEs, with installation first.
- Installation guides name the exact folder to select for each download.

Automatic checks still follow your configured interval and pause when Scholar requests verification or restricts access. Citation-source pages are recorded only when you visit them yourself.

## Install

1. Download **citelog-chrome.zip** from Assets below. Unzip it into a folder named **`citelog-chrome`** and keep it in a permanent location.
2. Open `chrome://extensions` and turn on **Developer mode**.
3. Click **Load unpacked** and select the **`citelog-chrome` folder**.
4. Pin CiteLog, open it, paste your Google Scholar profile URL, and click **绑定主页** (Bind profile).

## Update and keep your records

Copy the files from the new **`citelog-chrome` folder** into your **original installation folder**, replacing the old files. Then click **Reload** at `chrome://extensions` and refresh open Scholar tabs. Keep the original folder path and do not uninstall. Early local-trial users should continue using their original `extension/` folder.
