## 安装

1. [下载 **citelog-chrome.zip**](https://github.com/LilanOvO/citelog/releases/download/v0.1.5/citelog-chrome.zip)，解压为 **`citelog-chrome` 文件夹**，放在固定位置。
2. 在 Chrome 地址栏输入 `chrome://extensions`，开启「开发者模式」。
3. 点击「加载已解压的扩展程序」，选择 **`citelog-chrome` 文件夹**。
4. 固定 **CiteLog** 图标，打开弹窗，粘贴 Google Scholar 个人主页链接，点击「绑定主页」。

Chrome 116+ · 中文界面 · 无需注册或编译。

**更新插件：** 将新版文件覆盖到原安装文件夹，再点击「重新加载」。保持原文件夹不变，以保留记录。[安装帮助 →](docs/INSTALL.zh-CN.md)

## 功能

- **引用变化：** 总引用数、每日变化、哪些论文增加了引用。
- **检查与提醒：** 手动检查、自定义自动检查间隔、桌面通知。
- **引用来源：** 浏览 Scholar 来源页时保存文章，比较两次完整浏览，识别新增来源。
- **本地记录：** 数据保存在浏览器中，无服务器、广告或统计分析。

首次成功检查建立记录起点；每日变化按插件发现的时间记录。引用来源页需要你主动打开，插件不会自动抓取。
